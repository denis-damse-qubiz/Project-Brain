# Project Brain

A reusable knowledge structure for turning inputs into reviewable project knowledge without inventing facts.

Use `private-knowledgebase/` for personal working notes, `internal-knowledgebase/` for team-visible raw input and decisions, and `project-knowledgebase/` for material stakeholders may review.

Flow: record raw input or a dated decision, derive a sourced rule in a project spec, then add an observable scenario when applicable. Keep unanswered questions explicit. Never fabricate a project fact.
