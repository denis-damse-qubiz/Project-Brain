# Project knowledgebase

Use this area for material stakeholders may review. It contains the current agreed project view, not private notes or unverified assumptions.

- `specs/` holds current agreed behavior by area.
- `scenarios/` holds observable acceptance checks, matched by filename to the related spec.
- `adrs/` explains significant technical decisions.
- `transcripts/` holds stakeholder input.

Trace each rule to a shared raw input, stakeholder transcript, or dated decision. From that source, write the current spec rule and add a scenario when applicable. Keep unanswered questions explicit; never fabricate a project fact.
